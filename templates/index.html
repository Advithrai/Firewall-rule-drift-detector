How a flow is scored

  1. Read the flow

    42 flow features in UNSW-NB15 format: protocol, service, state, byte and packet counts, TTLs, rates and connection counts.

  2. Prepare it

    Protocol, service and state are label-encoded and every feature is standardised, exactly as during training.

  3. Score it

    The Tuned Random Forest (200 trees) returns the probability that the flow is traffic a correct policy would deny.

  4. Rank it

    The probability is mapped to Low, Medium, High or Critical, each with a recommended action.

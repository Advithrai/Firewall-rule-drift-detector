What the CSV needs

Required

  • A header row with the 42 UNSW-NB15 feature columns, spelled exactly as in the table below. Order does not matter.
  • One flow per row. Numbers only in numeric columns; no empty cells.
  • proto, service and state as text, using values that appear in UNSW-NB15 (listed below).
  • Comma-separated, UTF-8, up to 200,000 rows (about 200 MB).

Optional

  • label: 0 for normal, 1 for attack. Adds accuracy, precision, recall and a confusion matrix to the report.
  • attack_cat: the attack category (Normal, DoS, Exploits…). Together with label, adds detection rate per category.
  • id and any other extra columns are ignored.

The UNSW-NB15 training and testing CSVs already have this format, so you can upload them directly.
